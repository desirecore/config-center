# 来源文档模板导航

新增或更新时按用途分别维护，不将所有模型放进一份文档。

- [官网证据目录模板](templates/SOURCES.md)：放到 `providers/<supplier>/SOURCES.md`。
- [单模型模板](templates/MODEL.md)：放到 `providers/<supplier>/models/<model-id>.md`。
- [单接入面模板](templates/ACCESS.md)：放到 `providers/<supplier>/access/<category>--<id>.md`。

供应商 README 只导航上述文件。模板不参与来源校验；实际文件必须填写正确配置位置、精确 ID、来源目录引用、日期和 SHA-256。文件名与更新流程见 [MAINTENANCE.md](MAINTENANCE.md)。
