# PLAN：旧字段迁移、客户端门控、域名退役与模型规格优化

## 目标与基线

- config-center 基线：main `4f4e5093e91ead6c9f01aacc188d23ea4b5e8917`，presetDataVersion 127。
- 已发布客户端核查对象：[v10.0.177](https://github.com/desirecore/desirecore/releases/tag/v10.0.177)，tag commit `dd5a8c9f2fb000f7b2c589ec092068874c7dec5c`。release 标记为正式版本，发布时间 2026-09-27，targetCommitish 为 dev；主仓 main `412e05b...` 不能代替该发布基线。
- 范围：29 份 Provider、11 份套餐、23 份规格文件；340 条接入模型记录、279 条 ModelSpec，共 619 条来源记录。
- 当前 40 份接入配置仅 2 份有 requiredClientVersion。149 种 extra 叶路径出现在 233 条记录中；149 种不等于 149 个旧字段，全部需要完成消费/归属分类。
- 用已发布客户端的真实匹配器核对：303 exact、3 normalized、1 stripped、9 pattern、7 family、17 未匹配；45 条记录存在 contextWindow/maxOutputTokens 差异。58 条规格未被静态接入记录命中，不能据此认定无用，可能服务云端动态目录、历史身份或待适配协议。
- 本轮已迁移的 14 个无效推理键不再残留；下一阶段不能把“旧键告警为零”当作全部字段已规范。

## 推荐取舍

保留 Provider 与 model-specs。推荐“规格单处维护 + 接入面显式覆盖 + 编译得到有效配置与兼容副本”。不要合并成一个巨大 Provider 文件，也不要删掉 Provider 只留下规格。

| 域 | 唯一作者数据 | 不应承担 |
| --- | --- | --- |
| ModelSpec | 精确模型身份、原厂已核事实、输入/输出独立限制、模态与固有限制、模型级路由策略、证据和生命周期 | endpoint、凭据、账号开放名单、平台价格、接入 effort、thinking 回放或平台 WebSearch |
| Provider / 套餐 | 地域、端点、凭据、账号可用模型、协议/适配器、计价单位与价签、显式接入限制和 API 参数映射 | 再次手工复制所有模型事实、靠 family 推定新型号能力 |
| 编译器 / 客户端 resolver | 按字段规则组合 ModelSpec 与接入覆盖，记录每个有效值的来源，生成旧客户端副本 | 私自补 unknown、合并不同单位或把完整能力列表取并集 |
| 用户配置 | 用户选项、合法覆写和自建接入 | 被远端预设覆盖或被按名称猜测的迁移修改 |

格式路线：新增版本化 V2 目录/manifest/schema 与客户端读取选择器，旧路径维持冻结的 V1 兼容投影。新版本原始作者数据不再保留运行时旧字段；兼容投影由生成器产出，过渡期不手工双写。完成客户端铺开后停止更新旧投影并归档，移除条件必须明确。具体见[规格与接入职责设计](MODEL-SPECS.md)。

## 首批优先事项

1. **P0/P1，版本门控**：40份接入及279条规格声明其能力依赖。以已发布tag检查功能，证明升级前后的读取、拒绝和缓存行为；显示“需更新”之外，还要堵住显式Provider、SDK、工作流、后台辅助和媒体调用绕过。
2. **P3，GPT-5.4 Nano误匹配**：当前走 gpt-5.4 的 pattern，Nano 400000 窗口可能被 1050000 规格混淆。补独立exact规格、收窄pattern，并用真实匹配器验证；其他代际误吞一并巡检。
3. **P3，独立输入限制**：Mini/Nano 的272000输入与400000总窗口、讯飞65536输入与131072输出分别表达；不再用 contextWindow 伪装最大输入。
4. **P0/P2，参数差异**：Codex订阅272000与原厂1050000不是自动错误；MiniMax-M3共享输出512000与直连131072证据仍不完整；OpenRouter上限按其独立合同处理。见[匹配与差异基线](SPEC-BASELINE.md)。
5. **P0/P4，历史下架接入**：零一万物已由本仓#84删除，但已发布客户端退役名单仅见internal-testing。补受管旧配置迁移；“本产品已下架”与“厂家域名已停止服务”的证明分别登记，不能直接封整个lingyiwanwu.com。
6. **P2，定价/媒体/思考旧字段**：价格同义字段、音频格式/音色、思考默认和旧metadata优先分类；不把缓存读价、TTL写价、按字符/每秒/每search unit价格改成同一token价。

## 并行实施安排

本次实施采用三个 subAgent 与主工作线协作。配置中心复用当前工作区；客户端从最新dev创建隔离worktree，按要求拉取最新子模块。

- A：字段归属、迁移器与兼容投影；独占迁移工具、字段schema和迁移测试。
- B：ModelSpec精确绑定、参数与官方字段核查；按供应商分工，不同时修改同一 canonical。
- C：域名/Provider退役清单、客户端停用与出站拦截；独占退役注册与相关测试。
- 主工作线：客户端版本矩阵、格式门控、resolver接口、交叉review、manifest和发布；共享schema变更先定接口再分配，不能多代理同时改同一文件。

P0 的只读清单可并行；P1 完成后再进行数据迁移和下架发布。客户端仓 worktree 若需建立，先同步并更新最新子模块，保留无关gitlink及用户改动。
