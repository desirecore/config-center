## 并行边界

- 推理与历史工作线独占 OpenAI、xAI、智谱、DeepSeek 和匿名历史规格；百炼套餐中对应 DeepSeek 单条来源由该工作线同步。
- 工具与非模型工作线独占 tools、docs/data-sources、独立校验、package scripts 和对应测试。
- 运行时工作线独占 runtimes、docs/runtime-sources、刷新脚本和对应测试。
- 主工作线负责其余供应商的官网核验、总体来源规则、未完成接入清单、manifest 与最终 review。
- 所有工作使用同一 checkout，保留 logs 等无关文件；不并行修改同一文件，不在子任务中提交。

## 合并工作线后的门禁

1. 对照最新版 origin/main 确认没有混入其他变更，审查差异中的数据是否有字段级依据。
2. 运行来源校验、完整配置校验、测试和 git diff --check。
3. 只有预设数据变化才递增 manifest；文档和工具改造不单独递增。
4. 逐项报告完成内容、证据限制和跨仓依赖；官网读取、Schema 通过不代替真实账号调用。
5. 按已有授权完成提交、PR、受保护合并及远端 CI 复查。

后续结果见 [本轮执行记录](RESULTS.md)。每家供应商的具体证据仍保存在各自来源目录，不在此重复拼成总证据表。
