# 历史审计工具

四个旧 ZenMux 入口已停用，执行时失败且不读取或写入配置。原始代码保存在 `archive/*.mjs.txt`，仅作历史追溯；其中硬编码路径、固定日期、归一化/相似匹配、第三方价格自动覆写均不再是维护流程。不要改名恢复执行。

后续工具必须以仓库根目录参数或脚本相对路径定位，输出目录显式指定；候选差异只读、不自动 apply。第三方目录可作为寻找官方证据的线索，不能作为原厂模型参数与定价的事实来源。记录官网字段证据后人工做精确 ID 差异，同步分接入面来源、manifest、测试，再走 AGENTS.md 的发布检查。

当前可用检查：`npm run validate`、`npm run validate:data-sources`。这些命令不请求供应商 API、不产生候选参数、不更新预设。
